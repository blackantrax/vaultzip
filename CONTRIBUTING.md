# Contributing

Thank you for helping. Before opening a pull request:

1. Run `cargo fmt --all` and `cargo clippy --workspace --all-targets -- -D warnings`
2. Run `cargo test --workspace` and add tests for any new behavior
3. Keep security-sensitive changes small and well explained

By contributing you agree your work is released under the MIT license.

## Dependencies

Only add dependencies licensed under MIT, Apache-2.0, BSD or similar permissive terms. Avoid GPL or LGPL code in the core so the project stays easy to adopt and relicense.
